# Prompts

Cada versão do prompt de extração fica em um arquivo próprio: `v1.md`, `v2.md`, ...

- Mude **uma coisa por vez** entre versões (instrução, definição de categoria ou exemplos).
- Registre no topo de cada arquivo o que mudou em relação à versão anterior.
- Os resultados de cada versão vão para o relatório de testes, para comparar v1 e v2 com números.
- O relato do cliente deve entrar no prompt delimitado e tratado como dado, nunca como instrução.
